How-To: Coinbase API Keys
Step-by-step guide to get your Coinbase Advanced Trade API credentials.


        

          
Step 1: Create a Coinbase Account

          

            
    
              
  1. Go to coinbase.com and click Get Started
    2. 
              
  2. Enter your name, email, and create a strong password
    3. 
              
  3. Verify your email address via the link Coinbase sends
    4. 
              
  4. Complete identity verification (ID + selfie) — required for trading
    5. 
              
  5. Add a payment method (bank account, debit card, or wire transfer)
    6. 
              
  6. Buy at least ~$50 of USDT or USDC on the main Coinbase app
    7. 
            

          

        


        

          
Step 2: Access Coinbase Advanced Trade

          

            
    
              
  1. Go to trade.coinbase.com (this is Coinbase Advanced Trade)
    2. 
              
  2. Your USDT/USDC from step 1 should appear in your portfolio
    3. 
              
  3. If not, click Transfer → move from Coinbase main to Advanced Trade
    4. 
              
  4. Verify you can see USDT/USDC balance available for trading
    5. 
            

          

        


        

          
Step 3: Create Advanced Trade API Key

          

            
    
              
  1. Go to coinbase.com/orders → click API (top right)
    2. 
              
  2. Or visit cdp.coinbase.com directly
    3. 
              
  3. Click New API Key → select Advanced Trade API
    4. 
              
  4. Name it (e.g., hermes)
    5. 
              
  5. Permissions: check View (read balances/products) and Trade (place/cancel orders)
    6. 
              
  6. Create an API key — write down the passphrase if shown; some setups do not use one
    7. 
              
  7. Complete 2FA if prompted
    8. 
              
  8. Copy both values immediately — the Private Key is shown ONCE ONLY
    9. 
            

            

              ⚠ The Private Key is base64-encoded. Do not modify it. Store your API Key Name and Private Key securely. If a passphrase is shown, store that too.
            

          

        


        

          
Step 4: Save Keys to Compendium File

          

            
    
              
  1. Open the Setup tab in this app
    2. 
              
  2. Scroll to Coinbase API Keys section
    3. 
              
  3. Paste your API Key Name and Private Key
    4. 
              
  4. If your file includes a passphrase, paste it too; otherwise leave it blank
    5. 
              
  5. Click Save & Write Compendium — this creates the credentials file Hermes reads
    6. 
              
  6. Example file format:
    7. 
            

            
API Key Name: organizations/.../apiKeys/...
Private Key: u6DRGN3Zoc1b6FgT8yfXJc3HOdkpHds4reGbLYXAxXGPZGAA8N/HCQqi53ZjAjipN2H09oBEwovEP6zujVDu7A==

# AI Credentials (Nous Portal)
NOUS_API_KEY: ...
NOUS_MODEL: ...

              
  • The file is what Hermes reads for your cron trading job
    • 
            
          
    
        
    

        
    
          
    Step 5: Install & Configure Hermes
    
          
    
            
      
              
    1. Go to the Hermes tab in this app
      2. 
              
    2. Step 0: Click Add Defender Exclusion (prevents false positive)
      3. 
              
    3. Step 1: Click Install Hermes — wait 2–5 minutes
      4. 
              
    4. Step 2: Click Write Compendium File
      5. 
              
    5. Step 3: Click Start Dashboard + Gateway
      6. 
              
    6. Step 4: Click Auto-Configure Cron — creates coinbase-perp-trading cron
      7. 
            
    
          
    
        
    

        
    
          
    Step 6: Verify It's Working
    
          
    
            
      
              
    1. Wait 1–3 minutes after cron is configured
      2. 
              
    2. Check Logs tab — you should see Hermes output
      3. 
              
    3. Check Coinbase Advanced Trade → Positions/Order History for trades
      4. 
              
    4. In Hermes dashboard (embedded), click Chats — new entry every ~1 min
      5. 
              
    5. Go to the Trading tab and click Voice to enable position announcements
      6. 
              
    6. When a position opens, the app announces Opened [symbol]; when it closes, it announces Closed [symbol]
      7. 
              
    7. To reduce resource usage, minimize the app — it will keep running in the system tray
      8. 
              
    8. Click the tray icon to restore the window, or choose Quit from the tray menu
      9. 
            
    
          
    
        
    

        
    
          
    Keep Your Computer Awake & Connected
    
          
    
            
    This agent is meant to run unattended. If your computer falls asleep or loses internet, the scheduled trading checks won't run.
    
            
    Windows: Open Settings → System → Power & battery → set Screen and Sleep to Never while plugged in. If you use a laptop, keep it plugged in during long runs.
    
            
    Mac: Open System Settings → Displays → set Turn display off to a longer interval, or use caffeinate in Terminal for a no-sleep session. If you want it automatic, consider a trusted power/no-sleep utility.
    
            
    Internet: A wired connection is the most reliable. If you use Wi-Fi, make sure your router doesn't aggressively drop idle connections.
    
          
    
        
    

        
    
          
    ⚠ Important Notes for First-Time Users
    
          
    
            
      
              
    • Risk: Trading can lose money. Only use funds you can afford to lose.
      • 
              
    • Private Key: Shown ONCE when created. If lost, you must create a new API key.
      • 
              
    • Passphrase: Optional in many Coinbase setups. Store it only if your API key shows one.
      • 
              
    • Perpetual Futures: The cron trades Coinbase perpetual futures (e.g., BTC-USD PERP) — different from spot trading.
      • 
              
    • Stay Awake & Connected: Use the guidance above so the agent can keep running on schedule.
